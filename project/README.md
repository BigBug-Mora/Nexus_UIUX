# Future project folders

This scaffold keeps the next round ready for design work. The [Round 1 working pack](../proposal/README.md) lives separately at the repository root.

| Folder | Intended use |
| --- | --- |
| `design/flows/` | User flows, role transitions and state diagrams |
| `design/wireframes/` | Team-authored rough sketches and revisions |
| `design/ui/` | High-fidelity layouts, components and language variants |
| `prototype/` | Figma view link or prototype source once chosen |
| `research/synthesis/` | Anonymized themes and approved aggregate findings |
| `research/usability/` | Test scenarios and anonymized usability results |
| `assets/` | Original or licensed assets with source and attribution notes |
| `exports/` | Competition-ready exports and design rationale |

Empty folders have Git placeholders. Store raw participant records in an approved restricted location outside the repo.
